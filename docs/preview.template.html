Honest limitations

The model is small. A 0.8M-parameter character transformer proves the pipeline, not frontier capability. The market test is narrow. Five liquid US symbols over five years, with a simplified cost model. Two hypotheses failed. We keep them in the headline instead of hiding them. Live data moves. Re-running today will produce a new snapshot; the committed results record the exact retrieval time.

Questions

The things people ask before they trust a benchmark.

Is this another LLM leaderboard?

No. It does not rank commercial models. It tests whether the foundations people claim to implement — gradients, attention, a small transformer, a market hypothesis — actually behave as advertised.

Why report failed hypotheses?

Because pre-registration only means something if failures are visible. H4 (activation effects) and H6 (market structure plus no alpha) did not meet their strict criteria. Reporting that is the product.

Can I use it commercially?

Yes. The code is MIT licensed. You can use it internally, in products, or in client work. Attribution is appreciated but not required.

How long does it take?

The fast checks take seconds. The full six-study suite takes about 15 minutes on a modern CPU. The transformer study dominates the runtime.

Do I need a GPU?

No. The NumPy model and the small PyTorch transformer run on CPU. Docker is the recommended path because it pins the environment.

What if I disagree with a result?

Good. The protocol, code, data hashes, and result JSON are all available. Open an issue with a concrete reproduction or a proposed deviation; the process is designed for that.
